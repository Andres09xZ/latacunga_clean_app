┌────────────────────────────────────────────────────────────────────────────┐
│                         📊 FLUJO DE PRUEBA                                 │
└────────────────────────────────────────────────────────────────────────────┘

PASO 1: Onboarding del Operador 🚶
├─ POST /api/v1/auth/operators
├─ Evento: identity.operator.created.v1
├─ Fleet consume y crea Driver
└─ ✓ Operador registrado y sincronizado

PASO 2: Inicio de Turno 🚛
├─ POST /api/v1/shifts/clock-in
├─ Asigna camión LAA-1020
└─ ✓ Conductor disponible

PASO 3: Generación de Demanda 📍
├─ 15x POST /api/v1/incidents (Zona 1)
├─ Validation calcula gravedad
├─ Scheduler acumula puntos
└─ ✓ Score ≥ 50 → Zona TRIGGERED

PASO 4: Asignación y Ruteo 🗺️
├─ Scheduler detecta zona triggered
├─ Fleet asigna conductor
├─ Routing calcula ruta (OSRM)
├─ Operations crea Work Order
└─ ✓ Orden ASIGNADA con paradas

PASO 5: Ejecución y Cierre ✅
├─ POST /orders/:id/start
├─ Nx POST /stops/:id/complete
├─ POST /orders/:id/finish
├─ Evento: workorder.completed.v1
├─ Fleet libera conductor
└─ ✓ Score → 0, Conductor DISPONIBLE

┌────────────────────────────────────────────────────────────────────────────┐
│                     ✅ CRITERIOS DE ÉXITO                                  │
└────────────────────────────────────────────────────────────────────────────┘

La prueba es EXITOSA cuando:

✅ Todos los servicios responden 200 en /health
✅ RabbitMQ está activo (puerto 5672 y 15672)
✅ Los 5 pasos se completan sin errores rojos
✅ Operador registrado correctamente
✅ Turno iniciado con camión asignado
✅ 15 incidentes creados en Zona 1
✅ Score de zona ≥ 50 (TRIGGERED)
✅ Orden de trabajo asignada con paradas
✅ Ruta (polyline) generada por OSRM
✅ Todas las paradas completadas
✅ Orden finalizada exitosamente
✅ Conductor liberado (DISPONIBLE)
✅ Score de zona reiniciado a 0
✅ Mensaje final: "🎉 ¡TESIS FUNCIONAL! 🎉"

┌────────────────────────────────────────────────────────────────────────────┐
│                   🔧 TROUBLESHOOTING RÁPIDO                                │
└────────────────────────────────────────────────────────────────────────────┘

Problema: "Service NOT AVAILABLE"
└─ Solución: docker-compose up -d

Problema: "No se encontró orden activa"
└─ Causa: Score < 50, RabbitMQ caído, o OSRM falló
└─ Solución: Ver logs de Scheduler, Routing y Operations

Problema: Timeout
└─ Solución: Aumentar timeouts en e2e_test.go

Problema: Datos duplicados
└─ Solución: .\cleanup_e2e_data.ps1
